``eigensolver="jd"`` no longer returns NaN when it reaches ``jd_outer``: it
returns its last Ritz pair and ``eigenpair``'s residual reports it. On a stable
equilibrium the lowest eigenvalue is zero to round-off, so the residual stop
(relative to ``gamma^2``) is never met and every such solve ended as NaN. NaN
is kept for a preconditioner block that is not positive definite at any shift
and for a non-finite result.
