``eigensolver="dense_mg"`` runs on ``jaxmg`` 1.2.0 with jax 0.11.0 as well as on
0.0.9. With 1.x there is one process per GPU, on one node or several, and the
matrix is overwritten instead of copied, so the 48x48x16 stellarator, family 1,
at ``penalty`` 1e-2 runs at 59.4 GB per GPU on one node instead of running out of
memory at 98 GB. Adds ``benchmarks/zernike_jd_vs_dense.py``, which compares JD
with the dense solve on the 96x96 tokamak and the 48x48x16 stellarator for
``penalty`` from 1e-2 to 1e4.
